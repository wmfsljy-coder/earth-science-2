## 한 단원의 구성

- **이야기 탭** — 한 편이 5장면 안팎. 첫 장면에서 학생이 먼저 예상(첫 추리)하고, 슬라이더·버튼으로 직접 조작해 미션을 풀고, 분류·순서 활동을 거쳐 결말에서 자기 말로 정리합니다.
- **수준별 문제** — 기본(개념) · 발전(해석·계산) · 심화(적용·논증). 문항마다 성취기준 코드가 붙어 있습니다.
- **응용 실험실** — 처음 보는 상황에서 예상 → 조작 → 판정 → 까닭 확인.
- **정리하기 · 우리 반** — 답안 복사, 반별 공유(별명 사용).

교사는 주소 끝에 `?open=1` 을 붙이면 모든 장면을 바로 열어 볼 수 있습니다.

## 내 학교에서 쓰기

1. 이 저장소를 **Fork** 하거나 *Use this template* 으로 복사합니다.
2. Settings → Pages → Branch 를 `main` / `(root)` 로 두면 몇 분 뒤 `https://<내 계정>.github.io/earth-science-2/` 에 열립니다.
3. **우리 반 공유**를 쓰려면 `assets/share-config.js` 의 주소를 내 Apps Script 웹 앱 주소로 바꿉니다(만드는 법: science-teacher-hub 의 [GUIDE.md](https://github.com/wmfsljy-coder/science-teacher-hub/blob/main/GUIDE.md)). 바꾸지 않으면 공유 기능만 꺼지고 나머지는 그대로 됩니다.
4. 반 목록을 고르게 하려면 `assets/share-config.js` 에 `window.STH_CLASSES = [{ v: "1-1", t: "1학년 1반" }, …]` 를 적습니다.
